# Web Photo Editor

A browser-based photo editing application built with HTML, CSS, and JavaScript.  
The app allows users to upload an image, edit it directly in the browser, and export the final result as a PNG file.

## Features

- Upload images from the local device
- Crop images using mouse-based selection
- Apply grayscale filter
- Resize images proportionally by width or height
- Add custom text on the image
- Export the edited image as a PNG file

## Technologies Used

- HTML
- CSS
- JavaScript
- HTML5 Canvas API
- File API
